Most features described here are targets, **not implemented software**. The documentation includes proposed choices that still need architecture decision records and test evidence. No native Windows GUI or installable executable is created by this documentation package.

**Canonical documentation authority:** the frozen 60 decisions + Decision 61. The master specification is a convenient combined read-through; the modular Markdown files support issue tracking, code review and ADR revisions. This dossier has no claim to legal/scientific certification.
